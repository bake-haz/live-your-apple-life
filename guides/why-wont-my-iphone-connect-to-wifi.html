Why Won't My iPhone Connect to Wi-Fi?

Before changing any settings, try your iPhone on another Wi-Fi network. That one test shows whether the phone or the network is the trouble.

You're probably here because your iPhone won't join a Wi-Fi network, joins but shows no internet, or drops the connection after a while. It feels personal, like the phone is being difficult. What you want to know first isn't how to reset something — it's who's at fault: the phone, this particular network, or the internet connection behind it.
Short answer: try another Wi-Fi network first. If it connects somewhere else, the phone can connect, so the problem is specific to the original network. If no Wi-Fi works anywhere, the iPhone deserves a closer look. Settle that before you change anything on the phone.

Try another Wi-Fi network first

One test outweighs a long checklist: try another Wi-Fi network — a friend's home, a café, or any network you trust.

  • Another Wi-Fi works. The phone can connect, so the original network is the more likely source of the trouble. Check that network's password, router, or sign-in page before touching the iPhone.
  • No Wi-Fi works. The phone fails everywhere you try it. Now the iPhone itself is worth a closer look.

Three different ways the problem shows up

A Wi-Fi problem can look like three different things, and each one points to a different fix:

  • Can't join the network. The iPhone never completes joining — the network doesn't appear, the password is rejected, or the join simply fails. Check the network name and password, whether the network is hidden or restricted, and who manages it.
  • Joined, but no internet. The iPhone connects and shows a checkmark, but nothing loads. The wireless link worked; the trouble is in the path to the internet — the router, the provider, or a sign-in page you haven't finished yet.
  • Connects, then drops. The phone joins, then loses the connection later. Notice whether it drops on every network or only this one, and whether other devices drop too.

A quick pass through the iPhone's settings

If you do touch the phone, keep it to the checks Apple lists first (Apple Support, "If you can't connect to Wi-Fi on your iPhone or iPad"):

  • Settings > Wi-Fi. Wi-Fi is on, and the network you want shows a blue checkmark once you're joined.
  • Airplane Mode is off. Turning on Airplane Mode switches Wi-Fi off, but you can switch Wi-Fi back on without leaving Airplane Mode. If the phone won't connect, check that Airplane Mode is off and Wi-Fi is still on.
  • Wi-Fi Assist. In Settings > Cellular, when this is on, the iPhone can use cellular data when a Wi-Fi connection is poor. It's designed to keep you online, and it means traffic can move to cellular when you expected Wi-Fi; turning it off makes Wi-Fi behavior more predictable.
  • Greyed-out Wi-Fi setting. If the Wi-Fi control is dimmed, restart the iPhone — hold the side button and a volume button, then slide to power off.
  • VPN or security software. A VPN profile or security app can reroute or block Wi-Fi. If you've installed one, remove it, restart, and test again.

These are checks, not resets. Nothing here erases your data, and Apple's own ordering keeps the router and network checks ahead of the one real reset (below).

When only this network misbehaves

Once you know the phone connects elsewhere, the question is why this network is different:

  • Other devices also can't get online through this Wi-Fi. The network side looks responsible. Restart the router and modem — unplug them, then plug them back in. If that changes nothing, the internet connection or provider is worth a call.
  • This network works for other devices, and only the iPhone struggles — while the iPhone works elsewhere. The trouble narrows to the relationship between this network and this device: a saved password, a required sign-in, or a setting this network expects.
  • The network is managed by someone else — work, school, a hotel. Managed networks can block unknown devices, hide the network name, or need a separate sign-in, and their rules are set by an administrator. Ask the network's owner (or their IT) rather than changing the iPhone — including whether that network needs Private Wi-Fi Address turned off for that network, which is normally best left on.

If the network is yours and it works for other devices but not the iPhone, forgetting the network and rejoining it — tap the name, choose Forget This Network, then rejoin with the password — clears a stuck saved connection before you go further.

When it connects but keeps dropping

First notice whether the drop follows the phone or the place: does it happen on only one network, and do other devices drop on that network too?

  • Drops only here, and other devices drop too — the router is the likely focus: restart it — unplug it, then plug it back in. If the drops continue, the router's placement or firmware is a network task, not a phone task.
  • Drops on every network you try — the iPhone side deserves the attention: restart the phone, remove VPN or security profiles, and if it still drops everywhere, the network-settings reset below is the last step to consider.
  • Not sure yet — move closer to the router to test whether distance is the cause, then try another network to see whether the drop follows the phone.

You don't need a theory about which band or channel is at fault. Trying another network, and watching whether other devices drop, shows whether the phone or the network is the cause.

Public Wi-Fi: joined is not the same as online

Cafés, hotels, and airports often use captive networks: joining the Wi-Fi is one step, and getting internet is a second step that can require a browser login, an email address, or accepting terms. If pages won't load on a public network, look for the sign-in page — opening Safari and loading any plain page brings it up — and complete it. Some public networks even tell the iPhone that the network isn't connected to the internet until the sign-in is finished. "Connected but no internet" at a coffee shop is expected until you approve access; that's the network's design, not a fault in the phone.

Reset Network Settings is a reset, not a diagnosis

The one real reset is Settings > General > Transfer or Reset iPhone > Reset > Reset Network Settings. It removes every saved Wi-Fi network and password, mobile settings, and VPN/APN configurations, then lets the phone rebuild them. Your photos, apps, and messages are untouched — but you will re-enter Wi-Fi passwords afterward.

A reset clears configuration; it doesn't tell you what was wrong. Apple is explicit that it belongs only after other solutions have failed, and that if a school or business configured your network, you should ask their IT or network administrator before resetting anything. The reasonable moment for it is when the problem follows the iPhone across multiple networks and the gentler checks above haven't resolved it — not as a first move, and not because a single network is being difficult.

You probably don't need to

You probably don't need to:

  • reset network settings as a first move — it's a reset, not a diagnosis, and it erases every saved network and password;
  • dig into advanced network settings, bands, or router features;
  • turn off Private Wi-Fi Address — it's on by default for good reason;
  • buy a new router before you've tested the iPhone on another network;
  • reset the whole iPhone.

Before any of those, the one step that settles it is trying your iPhone on another Wi-Fi network.
